# 🧮 Basic Calculator

A responsive and interactive calculator built using HTML5, CSS3, and JavaScript as part of my Day 7 Web Development Internship Task.

## 📌 Task

Build a calculator that supports:

- Addition
- Subtraction
- Multiplication
- Division
- Decimal values
- Clear functionality
- Equals functionality
- Divide-by-zero handling
## 🌐 Live Demo

[View Live Demo](https://vishal-maddheshiya.github.io/basic-calculator/)


## 🚀 Features

- Clean and responsive user interface
- Basic arithmetic operations
- Decimal number support
- AC (All Clear) button
- DEL button
- Divide-by-zero validation
- Keyboard support
- CSS Grid calculator layout
- DOM manipulation using JavaScript
- Event-driven interaction
- No use of `eval()`

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- DOM Manipulation
- JavaScript Event Handling
